# Archive

This directory contains development-era, superseded, or historical material retained for provenance. Nothing under `archive/` is required for the v2.0.0 reviewer-facing CPU reproduction unless an active test explicitly reads a historical extraction source for regression checking.

Use these active locations instead:

- `scripts/` for the publication analysis pipeline,
- `results/published/` for authoritative corrected results,
- `results/reference/` for minimal retained inputs,
- `figures/main/` for publication figures,
- `notebooks/extraction/` for GPU extraction notebooks,
- `docs/` for reviewer-facing documentation.

Historical material is intentionally not deleted because it documents the evolution of the analysis and preserves reproducibility context for earlier releases.
