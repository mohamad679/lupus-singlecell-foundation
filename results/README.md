# Results

`published/` is the authoritative v2.0.0 corrected analysis package.

`reference/` contains only the compact historical/reference donor-level inputs required by the corrected CPU reproduction. Historical development outputs that are not required for the publication reproduction are under `../archive/legacy_results/`.

The large historical pseudobulk parquet matrices are not stored on the active branch; they remain in the historical/release archive and are intended for Zenodo preservation.
